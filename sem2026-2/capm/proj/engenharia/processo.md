# Processo de software

O processo de software será o [OpenUP](https://www2.htw-dresden.de/~anke/openup/publish.openup.base/guidances/roadmaps/openup_roadmap_407D5269.html), que é um processo iterativo e incremental de desenvolvimento.  Na nossa implementação particular do processo, haverá, ao menos, 3 iterações onde cada uma delas será composta das seguintes fases:

1. Engenharia de requisitos
2. Projeto de software
3. Implementação e testes unitários
4. Testes de integração e implantação
