## Requisitos de Usuário
Declarações em linguagem natural (acrescidas de diagramas simples) sobre quais serviços o sistema deverá fornecer e quais serão suas restrições operacionais. São escritos prioritariamente para os clientes e usuários finais. Inclua aqui a elicitação de requisitos funcionais.

## Requisitos de Sistema
Versões expandidas e mais detalhadas dos requisitos de usuário, servindo como base para contratos de desenvolvimento. Eles descrevem detalhadamente as funções, serviços e restrições operacionais do sistema. Inclua aqui a elicitação de requisitos não funcionais.

## Especificação de Software
Uma descrição técnica detalhada que funciona como uma ponte entre a análise de requisitos e o design/arquitetura do software, direcionada especificamente para a equipe de desenvolvedores. Inclua aqui o modelo de negócio.
