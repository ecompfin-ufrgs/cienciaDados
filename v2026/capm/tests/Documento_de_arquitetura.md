
# Documento de arquitetura de software

## Estrutura geral

O software está organizado em duas partes principais, sendo a primeira um pipeline de dados (que visa executar o pré-processamento dos dados) e a segunda uma arquitetura Model-Viewer-Controller (MVC), com o objetivo de formatar a saída final dos dados e a utilização pelo usuário final.
