\section{Introdução}

Este documento apresenta os requisitos para o desenvolvimento de um
sistema de análise e seleção de carteiras de investimentos, baseado
no modelo de Markowitz (1952).

O sistema será desenvolvido como parte da disciplina de Ciência de
Dados em Economia e Finanças.

O objetivo deste documento é apresentar as necessidades do usuário,
definir o que o sistema deverá fazer e descrever os requisitos que
deverão ser atendidos durante seu desenvolvimento.

O documento está dividido em quatro partes principais:

\begin{itemize}
\item \textbf{Requisitos do Usuário:} apresentam o que o usuário
espera do sistema;

\item \textbf{Definição do Sistema:} descreve o objetivo, o escopo,
os usuários e as principais características do sistema;

\item \textbf{Projeto do Software:} descreve como o sistema será
organizado e como o modelo de Markowitz será utilizado em seu
desenvolvimento.
\end{itemize}
