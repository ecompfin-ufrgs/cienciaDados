# Projeto Black-Litterman

Ferramenta open source que calcula pesos de carteiras de ações brasileiras com o modelo Black-Litterman, incorporando as views do gestor.

O projeto tem dois produtos:

- **Webapp:** o usuário escolhe ativos de um catálogo com os 30 mais líquidos e calcula a carteira de hoje.
- **Estudo de backtest:** avalia o método com os 10 ativos mais líquidos em cada data.

Ferramenta acadêmica, sem recomendação de investimento.
