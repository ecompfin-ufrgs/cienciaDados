# Documentação de requisitos
Documentar requisitos é a atividade de produzir um documento que
resume e organiza os artefatos produzidos nas fases de elicitação e
análise, visando a elencar e explicar precisamente os requisitos dos
usuários e do sistema, excluindo dubiedades, contradições 

## Definição de Sistema
Requisitos do Sistema:

1. O sistema tem como ponto de partida o modelo CAPM
2. É necessário que o usuário informe a sua visão de mercado em relação ao retornos. Nesse caso ese deve informar ao modelo quais taxas de retorno serão as melhores na sua opinião, que pode divergir do que o mercado está prevendo.
3. O usuário deve informar o nivel de confiança sobre suas opiniões
Saida:
Com os retornos ajustados, com o modelo calculando a variância,, covariança e correlações, utilizado dados com informaççoes diárias, o modelo retorna a carteira final ótima  
## Especificação de requisitos de Sistema
Nesse contexto, o sistema possa usar um modelo CAPM externo (?), ou o modelo de Markowitz(?)
## Especificação de requisito do software

O sistema tem como objetivo final, encontar uma carteira de investimento ótima, levando em consideração a opinião do investidor e comparando com as tendencias do mercado, atraves de um modelo CAPM. É necessario que o usuário tenha um certo conhecimento de mercado financeiro sobre suas opinião , para que o modelo possa funcionar corretamente
